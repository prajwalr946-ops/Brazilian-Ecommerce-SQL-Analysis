# Brazilian E-commerce Business Analysis Using SQL

## Project Overview
This project analyses Brazilian e-commerce transactions using SQL to understand customer behaviour, order trends, sales performance, freight costs, delivery efficiency, and payment patterns.

The objective is to convert raw business data into meaningful insights and recommendations that can support better business and operational decisions.

## Business Objectives
- Analyse order growth and monthly demand patterns.
- Understand customer distribution across Brazilian states.
- Evaluate order value and freight expenses.
- Measure delivery performance against estimated delivery dates.
- Analyse customer payment preferences and installment patterns.
- Identify opportunities to improve logistics and customer experience.

## Tools & Technologies
- SQL
- Google BigQuery
- Relational database tables
- Data analysis and business reporting

## SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate functions (COUNT, SUM, AVG)
- Joins
- Common Table Expressions (CTEs)
- CASE statements
- Date and time functions
- Subqueries
- Window functions (DENSE_RANK)
- UNION ALL

## Analysis Performed

### 1. Exploratory Data Analysis
- Examined customer table structure and column data types.
- Identified the order date range.
- Analysed customer coverage across cities and states.

### 2. Order Trends and Seasonality
- Analysed yearly order growth.
- Examined monthly order patterns.
- Identified peak ordering periods.
- Categorised orders by time of day.

### 3. Regional Analysis
- Evaluated monthly orders across states.
- Analysed customer distribution by state.
- Identified high-performing and low-performing regions.

### 4. Sales and Freight Analysis
- Compared order payment values between 2017 and 2018 for January–August.
- Calculated total and average order values by state.
- Evaluated total and average freight expenses by state.

### 5. Delivery Performance
- Calculated actual delivery duration.
- Compared actual and estimated delivery dates.
- Identified states with higher and lower average freight costs.
- Ranked states based on delivery performance.
- Examined early deliveries compared with estimated dates.

### 6. Payment Analysis
- Analysed monthly orders by payment type.
- Examined order distribution by payment installments.

## Key Findings
- The dataset covers e-commerce orders from September 2016 to October 2018.
- Customers were spread across 27 states and 4,119 cities.
- Order volume increased significantly between 2017 and 2018.
- São Paulo (SP) had the largest customer base and order activity.
- Freight expenses varied considerably across states.
- Delivery performance differed across regions.
- Payment methods and installment preferences showed different usage patterns.

## Business Recommendations
- Strengthen inventory planning during peak-demand periods.
- Improve logistics coordination in regions with higher freight costs.
- Review delivery estimation methods to improve accuracy.
- Develop region-specific marketing strategies.
- Use payment trends to improve customer payment experiences.
